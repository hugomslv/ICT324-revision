Erreurs et pièges

Message d'erreur → cause → solution. La plupart des messages ont été reproduits réellement (ESLint 10, Vitest 5, JSDoc 4, Vite 8). Astuce : cherche un morceau du message avec Ctrl+K.

#Réflexes de débogage

  1. Lis le message en entier : le nom de la règle / le fichier / la ligne sont indiqués.
  2. Cherche le message ici (Ctrl K) ou dans la doc.
  3. Isole : npx eslint un_fichier.js, npx vitest run -t "nom".
  4. Config finale : npx eslint --print-config src/main.js.
  5. Repars d'un état qui marche : le projet modèle.
