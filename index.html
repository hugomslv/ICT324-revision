ICT-324 : révision hors-ligne

Première évaluation : jeudi 24 septembre ().

Tout ce site marche sans internet : cours, exemples testés, projets du cours triés, et les documentations officielles d'ESLint, Vitest, Vite et JSDoc. Appuie sur Ctrl K (ou /) pour tout rechercher.

#Ce qui est demandé

Étape Réseau Où réviser
Créer un projet Vite ✅ branché 1. Vite
Mettre en place les docs ESLint / Vitest / JSDoc sur le poste ❌ hors-ligne Docs hors-ligne, Docs officielles
Configurer un linter avec des règles à trouver dans la doc ❌ Tuto 1, 2. ESLint, 2b. Règles
Écrire des tests unitaires simples ❌ Tuto 2, 3. Vitest
Générer une documentation (images, README.md…) ❌ Tuto 3, 4. JSDoc, 5. README
Configurer le projet pour une publication FTP dans un dossier précis, sans erreurs (favicon, images…) « à l'aveugle » ❌ Tuto 4, 6. Build & FTP
🛑 Danger : La règle d'or

Pendant la phase avec réseau, installe toutes les dépendances dont tu auras besoin ensuite (eslint, @eslint/js, globals, vitest, @vitest/coverage-v8, jsdoc…). Une fois hors-ligne, npm install ne marchera plus. Tout est détaillé dans Jour J.
