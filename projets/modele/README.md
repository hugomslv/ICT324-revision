# Projet modèle ICT-324

Projet **Vite** avec linter **ESLint**, tests **Vitest** et documentation **JSDoc**.

![Capture du projet](./img/capture.png)

## Installation

```bash
npm install
```

## Commandes

| Commande | Rôle |
|---|---|
| `npm run dev` | Serveur de développement |
| `npm run lint` | Vérifie le code |
| `npm test` | Lance les tests |
| `npm run coverage` | Couverture de code |
| `npm run doc` | Génère la doc dans `docs/` |
| `npm run build` | Build de production dans `dist/` |

## Utilisation

```javascript
import { add } from "./src/math.js"
add(1, 2) // 3
```
